## 수동 테스트 시나리오

각 시나리오는 역할별 계정으로 진행합니다.

### 테스트 계정 준비

Firebase Console > Authentication에서 계정 생성 후,
Firestore `users` 컬렉션에 아래 문서를 추가합니다.

| 역할 | 이메일 예시 | role 값 |
|------|------------|---------|
| 관리자 | admin@test.com | `admin` |
| 현장 담당자 | agent@test.com | `agent` |
| 직원 | user@test.com | `user` |

### 시나리오 1 — 인증 흐름

| 번호 | 테스트 | 기대 결과 |
|------|--------|----------|
| 1-1 | 비로그인 상태에서 `/dashboard` 직접 접근 | `/login`으로 리다이렉트 |
| 1-2 | 잘못된 이메일/비밀번호로 로그인 시도 | 오류 메시지 표시 |
| 1-3 | user 계정으로 로그인 | 대시보드 진입, 사이드바에 티켓만 표시 |
| 1-4 | admin 계정으로 로그인 | 대시보드 진입, 사이드바에 통계/사용자관리 표시 |
| 1-5 | 로그아웃 | `/login`으로 이동, Hive 캐시 삭제 확인 |
